# 尺间

尺间是一款给绘画者用的离线 3D 透视练习台。你可以把一只茶壶摆上桌面，沿着桌边寻找消失点，也可以把一台相机放大到楼房那么高，从公交车旁仰望它。摆好场景后，直接在画面上起稿，再用辅助线和标尺核对自己的判断。

## 下载与打开

下载 [尺间离线版 v1.0.0（ZIP）](https://github.com/Aroetem/chijian-perspective/raw/refs/heads/main/chijian-offline-v1.0.0.zip)，解压后双击 **尺间-透视练习台.html**，用桌面浏览器打开即可。152 个模型、预览图和绘图工具都包含在文件里，断网也能练习。如果下载的是整个仓库，可以打开根目录中的 **index.html**。

## 可以练什么

- **结构与消失点**　用 44 种几何体练习孔洞、曲面与转折，也可以从 108 件生活和街景物件里挑一件熟悉的东西。切换线框，或拆开茶壶、打印机等组合模型，观察各个部件如何占据空间。
- **遮挡与堆叠**　一次随机生成 2–30 个物体，共有五档难度。基础场景适合观察同向边线；专家和大师场景会出现餐板上的茶具、分层摆放的推车，或由两个支点托起的横梁。
- **视角与巨大感**　在人眼平视、虫眼仰视和楼顶俯视之间切换，用同一组物体练习不同构图。近摄广角和远摄长焦可以对照观察前后景的大小变化。视平线与透视辅助线可以分别开关。
- **尺寸与画面比例**　在侧栏选主体和参照物，比较它们的宽、高、深，以及画面上的投影宽高。用一件物体的已知长度标定后，可以查看米或厘米。按住 **M** 才会出现临时尺寸线，松开即可继续画。

## 试画一张「巨物街口」

1. 在物体库的「组合布景」打开「巨物街口」。先找到前景的公交车，再看街道中央的双镜头相机。
2. 切到「虫眼仰视」，按 **B** 描出公交车顶和相机顶端。按 **H** 隐藏参考，看看只靠轮廓能否读出两者的远近和大小。
3. 再按 **H** 显示参考，在「尺度标尺」里把相机设为主体、公交车设为参照。比较模型高度比和画面高度比，然后换到「人眼平视」，观察哪一项随视角改变。
4. 在「导出」里选择 PNG 保存这张画，或选择场景 JSON 留待下次调整机位。临时尺寸标注不会进入导出的图。

## 保存与换设备

自动保存和练习册保存在当前浏览器中。移动或重命名网页、更换浏览器或设备前，请在「导出」中选择「备份当前场景和全部练习」。在新位置选择「打开场景或恢复备份」即可恢复。导入备份会合并练习册，并打开备份里的当前场景。早期版本导出的场景 JSON 也能直接打开。
